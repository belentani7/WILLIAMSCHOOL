# Requisitos del recorrido

1. Un navegador puede guardar varios perfiles locales con identificadores distintos.
2. El progreso se mide por IDs de módulo y lección ya existentes.
3. La primera lección está disponible. Cada siguiente exige la anterior completada.
4. Cambiar de perfil cambia progreso y bloqueos sin alterar las lecciones del currículo.
5. Los controles indican su estado a lector de pantalla y por texto, sin depender solo del color.
6. Un almacén no disponible no impide leer las lecciones durante la sesión.
