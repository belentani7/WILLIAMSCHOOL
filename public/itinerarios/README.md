# WILLIAMSCHOOL · Visor de currículo completo

Este módulo lee directamente tres JSON públicos del repositorio: asignaturas académicas, cursos comunitarios y rutas Omega. La vista de curso muestra todas las unidades, conceptos, ejemplos, ejercicios, materiales de lectura y laboratorios existentes en dichos JSON. No inventa acceso a un LMS externo ni certificaciones.

El progreso se guarda localmente, independiente de la aplicación principal.
